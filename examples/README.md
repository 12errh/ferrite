# examples/

Quickstart scripts referenced by `README.md` and `AGENTS.md`.

`collatz.py` and `test_collatz.py` land with the M1 exit gate (PLAN.md), which
requires `ferrite build` + `ferrite verify` to succeed on an iterative
`collatz_length`, a recursive `fibonacci`, and a `newton_sqrt`.

This directory is empty until then. Nothing here is a stub.
